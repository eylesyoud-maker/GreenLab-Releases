# GreenLab-Releases
GreenLab Music — современный музыкальный плеер для Android. Поиск треков онлайн, скачивание в локальную библиотеку, инновационный парящий UI с поддержкой жестов. Edge-to-Edge дизайн, умная авторизация (Google) и встроенная система автообновлений (OTA). Сделано с фокусом на минимализм и UX.
